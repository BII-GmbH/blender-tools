# Blender Tools for BII Gmbh

This repo contains plugins and pipelines around the popular [Blender](https://www.blender.org/) 3D modelling software.

For more information on the different tools, look for the respective README.md files.

## Plugins

Plugins are directly installed into Blender and add their functionality to the software. They can be downloaded in the release section of the repo or by zipping them.

## Pipelines

Pipelines automate workflows that a) take time and b) are tedious.
They run Blender in the background on a separate thread.
